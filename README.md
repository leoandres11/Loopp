# Loopp

### Advanced Audio & Video Player • Built with passion by Arif Khan ❤️

**Loopp** is a modern, lightweight, and powerful media player built for Android. It combines a smooth **audio & video playback experience** with an advanced file manager, giving you complete control over your media files and folders in one place.

---

## 🤖 Built with AI

Loopp was built **entirely with AI assistance** using **ChatGPT** and **Google AI Studio**.

I’m not a professional programmer, and I don’t have a traditional coding background. Instead, I designed the features, UI, behavior, and overall vision of Loopp, then used AI to turn those ideas into a working Android application.

This project is also a personal experiment in discovering **how far you can go with AI-assisted development—even without knowing how to code.**

> **Idea → Prompt → AI → Testing → Fixing → Repeat → Loopp 🚀**

Every bug, improvement, feature, and design change was tested and refined throughout development.

**Built with curiosity, AI, and a lot of trial and error. ❤️**

## 📁 Advanced File Manager

Loopp isn't just a player — it gives you powerful control over your entire media library.

### File & Folder Operations

You can manage your media files across folders with:

* 📋 Copy
* ✂️ Cut
* 📥 Paste
* 🗑️ Delete
* ✏️ Rename
* 📂 Move
* 📄 File information
* 📁 Folder navigation
* 📑 Multi-selection

### 🔄 Copy, Cut & Paste Anywhere

Select one or multiple **audio or video files**, copy or cut them, navigate through your folders, and paste them wherever you want.

The same file-management controls are available throughout the media folders, making it easy to organize large collections without leaving Loopp.

## 🛠️ File Management

Loopp gives you control over your media directly from the folder structure.

```text
Storage
├── Movies
│   ├── Movie 01.mp4
│   └── Movie 02.mkv
│
├── Music
│   ├── Song 01.mp3
│   └── Song 02.flac
│
└── Downloads
    ├── Video.mp4
    └── Audio.mp3
```

Select files → **Copy / Cut** → navigate to another folder → **Paste**.

Simple.

---

## 🎯 Why Loopp?

Most media players focus only on playback.

Most file managers focus only on files.

**Loopp combines both.**

You can discover your media, play it with advanced controls, and manage the actual files without constantly switching between different apps.
